## 🚀 نظرة سريعة

**NEXA** منصة اجتماعية غنية بالخصائص، واجهتها عربية (RTL) بطابع داكن نيون زجاجي، مصمّمة لتكون **مغرية، إدمانية، وممتعة**. تجمع بين:

| الميزة | الوصف |
|--------|-------|
| 📺 **بثّ مباشر تفاعلي** | مشغّل بثّ مع تفاعل لحظي، دردشة حيّة، هدايا، تصويت للجمهور، ومتابعة مباشرة |
| 🎙️ **مساحات صوتية متطوّرة** | غرف صوتية حيّة بصور المتحدثين ثلاثية الأبعاد، مؤشرات كلام، رفع يد، وتقنية عزل |
| 🌈 **منصة دعم صانعي المحتوى** | اشتراكات (Tiers)، أهداف شهرية، صندوق دعم مجتمعي، وأحدث الداعمين |
| 📣 **إعلانات الشركات** | حملات إعلانية داخل البثّ والمساحات، استهداف جمهور، ميزانيات وتقارير |
| 🤖 **محرّك ذكاء اصطناعي** | خوارزمية توصية، رصد اهتمامات، مواضيع رائجة لحظية، تحليل مشاعر وتفاعل |
| 💬 **موجز اجتماعي (مثل X)** | منشورات، إعجابات، إعادة نشر، تعليقات، ومشاركة |

## 🧰 التقنيات

- **React 18 + Vite 5** — واجهة سريعة وحديثة
- **CSS مخصّص** — نظام تصميم داكن نيون زجاجي، متجاوب مع الجوال
- بدون اعتماد على أي API خارجي — بياناتها محلية غنية، جاهزة للتشغيل فوراً

## ▶️ التشغيل

```bash
npm install
npm run dev      # يفتح على http://localhost:5173
```

للإنتاج:

```bash
npm run build    # يبني في dist/ ويمكن معاينته عبر npm run preview
```

## ⚡ خصائص قوية متقدمة

- **🖥️ مشاهدة متعددة** — شبكة مشاهدة حتى 4 بثوث مباشرة معاً، تبديل تخطيطات (2×2، 3×1، 4×1)، ومزج شبكة.
- **🎬 المقاطع القصيرة (Reels)** — مشغّل عمودي للقطات البثّ المقتطعة بالذكاء الاصطناعي، مع إعجاب ونشر مباشر.
- **🏆 البطولات الحيّة** — بطولات بجوائز، قرعة منافسة، لوحة متصدرين، وربط مباشر ببثّ البطولة.
- **📊 التحليلات الشاملة** — رسوم بيانية (خط، دائرة، أعمدة، قمع)، ساعات الذروة، تغطية مناطق، وفهم للاحتفاظ.
- **🤖 استوديو الذكاء الاصطناعي** — توليد منشورات، موضوعات بثّ، مقاطع، ردود، وعناوين إعلانية مع ناتج لحظي.
- **🪙 اقتصاد النقاط (XP/المستويات/السلسلة/المتجر)** — كسب نقاط من كل تفاعل، مستويات وشارات، محفظة، ومتجر منتجات.
- **🚀 مشغّل فيديو بثّ محاكى كاملاً** — محرّك عرض (Canvas) يولّد "بثّاً" لحظياً مع تحكم حقيقي: تشغيل/إيقاف، شريط تقدّم وتقديم/تأخير، مستوى صوت، جودة (4K→480p/Auto)، ملء الشاشة، صورة داخل صورة، لقطة شاشة، ترجمات، ومؤشر بثّ/عَرجلة.
- **💱 عملات حقيقية قابلة للتحويل** — محفظة بأسعار صرف لحظية (USD/SAR/USDT/EUR/AED)، محوّل بين العملات، سحب عبر بنك/USDT/PayPal/STC Pay برسوم، وسجلّ تبادل وسحب.
- **🎵 صوت بثّ حيّ فعلي** — محرّك صوت (Web Audio) يولّد موسيقى خلفية + ضجيج جمهور لكل بثّ، متحكَّم به بمستوى الصوت/كتم وزر تشغيل، مع مؤشّر «صوت حيّ».
- **🤖 تعليق ذكاء اصطناعي تلقائي** — مساعد AI يعلّق خلال المشاهدة (أعلى المشغّل) + لوحة «مرافقة حيّة» في صفحة البثّ تعرض تحليلاً لحظياً للمزاج والتفاعل والنصائح.
- **🎨 إعدادات غنية ومريحة** — لوحة إعدادات كاملة تُحفظ على جهازك وتُطبَّق لحظياً: 4 سمات (ليلي/منتصف الليل/نهاري/دافئ للعناية بالعين)، 6 ألوان مميّزة، 3 كثافات، 4 مقاسات خط، استدارة، نوع خط، أوضاع راحة (تقليل الحركة/الوهج/تباين عالٍ/تعتيم)، وتفضيلات مشغّل وإشعارات ولغة واتجاه (RTL/LTR) وخصوصية.
- **🌗 وضع ليلي ذكي قابل للتعديل** — حرية كاملة من الإعدادات: تحكم **يدوي**، أو **تلقائي** حسب وقت اليوم، أو **بجدول مخصّص** (مثال 21:00-07:00)، مع اختيار سمة الليل وسمة النهار، وتتبّل تلقائياً مع مرور الوقت.
- **☁️ مزامنة ونسخ احتياطي** — حفظ الإعدادات مع حسابك، مع **رمز نسخ احتياطي** تولّده وتشاركه لاستعادة تفضيلاتك على جهاز آخر.
- **🧭 نظام توجيه مترابط** — كل هذه الأدوات تربط بينها عبر البحث الشامل، الملفات الشخصية، والإشعارات.

## 🗺️ صفحات المنصة

كل أرجاء المنصة مترابطة كمنتج واحد:

- **بحث شامل** — يفتّش في كل المنصّة (مستخدمين، بثّ، مساحات، منشورات، علامات) وينقلك مباشرة للنتيجة.
- **ملف شخصي عام** — أي صورة/اسم في أي مكان يفتح نافذة ملف موحّدة (بثّ / مساحات / دعم).
- **إشعارات حيّة** — تُحدَّث عند المتابعة والدعم، مع إغلاق للعنصر والانتقال للصفحة ذات الصلة.
- **حالة متابعة مشتركة** — زرُ متابعة واحد في كل المنصة (البثّ، الملف، الشريط الجانبي).
- **توجيه مترابط** — من بحث/مواضيع رائجة/توصيات AI تنتقل للبثّ أو المساحة المعنية مباشرة.
- **شريط بثّ عائم** — بثّ حيّ حاضر في كل الصفحات، ونافذة «ابدأ بثّ» لتشغيل البثّ فوراً.

## 🗺️ صفحات المنصة

1. **الرئيسية** — بثّ حيّ + موجز غذائي متدفّق + منشئ منشور
